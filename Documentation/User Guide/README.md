# Calendar Time Logger User Guide

How to use Calendar Time Logger 1.4.0 on macOS 27. Every page describes what the app does today; nothing here is planned work. For a shorter introduction, installation, and building from source, see the project [README](../../README.md).

![The Calendar Time Logger dashboard with no session running, showing Ready to work, recent templates, Today's Progress, Quick Actions, and Today's Work](../Design/Screenshots/01-dashboard.png)

## What Calendar Time Logger is

A Mac app that records the work you actually do, while you do it. You start a session from a template (or a quick task), pause and resume as you go, and choose **Finish Work** when you stop. The session is saved to your Work Logs, then written to Apple Calendar using its real start and finish times. Categories and task priority tell you what kind of work it was; Analytics and Excel export tell you where your time went.

## The one rule worth knowing

Calendar Time Logger records work **as it happens**. Starting a template puts nothing in Apple Calendar. When you choose **Finish Work**, the session is saved to your Work Logs first, and only then written to Calendar, using the real start and finish times. A template's settings describe *how* work is recorded, never how long an event will be.
